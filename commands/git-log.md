# Vault git log

Show history for the **vault** repository only (not the parent repo).

## Quick usage

```bash
llm-wiki git log
llm-wiki git query
```

Optional filters: pass flags supported by **`llm-wiki git`** — see **`llm-wiki git --help`**.
