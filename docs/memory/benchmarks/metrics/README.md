# Benchmark run history (optional)

When `benchmark.append_repo_runs_jsonl` is `true` in vault `config.json`, each benchmark run appends one JSON line here (`runs.jsonl`) for chart-friendly, git-tracked history. Default is `false` so normal runs do not dirty the repo.
